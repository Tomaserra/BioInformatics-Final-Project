1. Introduction

The Challenge: Alzheimer’s Disease

Clinical Features

Progressive neurodegenerative disorder with memory loss and cognitive decline

Pathological Hallmarks

  • Amyloid-β plaques
  • Tau tangles
  • Neuronal loss

Braak Staging (0-6)

Measures Tau distribution from transentorhinal (I-II) → limbic (III-IV) → neocortical (V-VI)

Our Approach: Use DNA methylation patterns to predict AD status

DNA Methylation & Study Design

What is Methylation?

Epigenetic modification (CH₃ groups) at CpG sites that regulates gene expression without changing DNA sequence

Why M-values?

\(M = \log_2\left(\frac{\beta}{1-\beta}\right)\)

  • β-values (0-1): Heteroscedastic, bounded
  • M-values (-∞ to +∞): Homoscedastic, unbounded
  • Better for linear modeling

Dataset: GSE66351

  • Platform: Illumina HumanMethylation450
  • Samples: 190 post-mortem brain tissues
  • CpG sites: 485,577 tested
  • Variables: Diagnosis, Age, Sex, Braak stage, Cell type, Brain region

Sample Distribution:

  • AD: 106 | Controls: 84
  • Age: 74.3 ± 15.1 years

2. Feature Selection

The Dimensionality Challenge

The Problem

  • 485,577 CpG sites
  • Only 190 samples
  • Ratio: 2,556:1

Consequences

✗ Severe overfitting
✗ Multiple testing burden
✗ Computational impractical
✗ Loss of statistical power

Solution

  1. Feature selection via linear regression
  2. Predictive modeling with selected CpGs

Linear Model:

\[M_{ij} = \beta_0 + \beta_1 \cdot Braak_i + \beta_2 \cdot Covariates_i + \epsilon_{ij}\]

Tests association with disease progression

Multiple Testing & Results

Correction Strategy

Method Threshold Significant
Uncorrected p < 0.05 63078
FDR q < 0.05 3262
Bonferroni p < 1.03×10⁻⁷ 72

Choice: Bonferroni — Maximum stringency for clinical reliability

Sample Size Calculation

  • Limiting class: 84 samples
  • 15:1 rule → Max 5 predictors
  • After covariates → 5 CpGs max

Final: 5 CpGs — Balance power & overfitting

3. Predictive Modeling

Model Development & Validation

Logistic Regression

\[\log\left(\frac{P(AD)}{1-P(AD)}\right) = \beta_0 + \sum \beta_i M_i + \beta_{cov} X_{cov}\]

Training Strategy

  • 70/30 stratified split
  • Training: 129 | Test: 55
  • AD ratio: ~54%

Interpretation

  • β: Log-odds change
  • OR (e^β): Multiplicative effect

Performance Metrics

Generalization: Δ = 9.9%

  4. Performance metrics
  5. Helper functions

  • Age, Sex, Cell type, Region

Usage Example

# Load model
model_pkg <- readRDS('alzheimers_model_api.rds')

# Prepare sample
new_data <- data.frame(
  M_1 = -2.1, M_2 = 1.8,
  # ... other M-values
  age = 78, sex = "Female",
  cell_type = "bulk",
  region = "frontal cortex"
)

# Predict
prob <- predict(model_pkg$model, 
                new_data, 
                type = "response")

# Interpret
if (prob > 0.5) {
  paste("AD predicted:", 
        round(prob*100, 1), "%")
}

Usage Example: Python

import requests

# Step 1: Convert Beta to M-values
beta_response = requests.post(
    "http://localhost:8000/convert-beta-to-m",
    json={
        "beta_values": [0.52, 0.68, 0.45, 
                       0.71, 0.38, 0.64, 
                       0.49, 0.58, 0.67, 0.42]
    }
)
m_values = beta_response.json()["m_values"]

# Step 2: Make prediction
prediction = requests.post(
    "http://localhost:8000/predict",
    json={
        "M_values": m_values,
        "age": 75,
        "sex": "M", 
        "cell_type": "neuron",
        "region": "frontal cortex"
    }
)

result = prediction.json()
print(f"Risk: {result['prediction']['risk_level']}")
print(f"Prob: {result['prediction']['probability_percent']}")
